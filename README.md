# 🎨 Random Color Generator

## Description
A simple Random Color Generator built using HTML, CSS, and JavaScript that generates random colors and displays their HEX codes with a copy option.

## Purpose
The purpose of this project is to practice JavaScript functions, loops, random number generation, DOM manipulation, and event handling by building an interactive web application.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Generate random colors with a button click
- Display the HEX color code
- Change the background color dynamically
- Copy the HEX color code to the clipboard
- Smooth color transition effects
- Simple and responsive user interface

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click **Generate Color** to create a random color.
5. Click **Copy Color Code** to copy the HEX code.
